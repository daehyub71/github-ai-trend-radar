## 1. IA (정보 구조)

```
/                      이번 주 (최신 주)
├─ ?week=YYYY-MM-DD    지난 주 (소급 주 포함 — "소급" 표시)
├─ /repo/<owner>/<name>  저장소 상세
└─ /about              지수는 이렇게 만든다 (방법·출처·한계)
```

- 머리 메뉴 3개: 이번 주 · 저장소 · 지수는 이렇게. 주 선택은 이번 주 화면 머리에.
- 모든 화면 바닥글에 출처 표기(star-trend 공개 데이터 · GitHub API · pypistats·npm · **ecosyste.ms** · HN·GeekNews)와
  "숫자는 코드가, 글은 AI 초안을 사람이 검토" 안내 (TASKS T4-5).
- 사이트는 `data/site/` 파생 데이터를 읽는다(T4-3). 블로그 초안은 사이트에 넣지 않는다 — 비공개 저장소에만(D7).
  **저장소 해설(F10)** 은 예외로, 비공개 저장소의 `site-private/` 를 빌드 때 받아 저장소 화면과 TOP 10 한 줄에 보인다(D13, 시안 v2).

## 2. 와이어프레임 (화면별 구성)

### 2-1. 이번 주 `/`
1. 머리: 로고 · 메뉴 · 주 선택
2. 어두운 히어로: 기간·회차 · 한 줄 제목 · 숫자 3개(후보 수 · 스타 TOP 10 중 지수 TOP 10 · 패키지 확인 후보) · 가중치 범례
3. **종합 TOP 10 표**: 순위 · 저장소(+카테고리 칩) · 지수 · **신호 기여 쌓은 막대**(합 = 지수) · 스타 순위 · 빠진 신호 칩(점선)
   - (v2, D16) 저장소 이름 아래에 AI 해설의 "이번 주 왜 올랐나" 한 줄 + 보라 "AI" 표시. 해설이 없는 저장소는 줄을 비운다
4. **신호별 TOP 5** 카드 5개(스타·기여·사용·언급·포크). 값이 없으면 언제 채워지는지 안내
5. **관점 노트** 카드 A~D(규칙 한 줄 + 저장소·근거 숫자). 이력 부족이면 안내
6. 바닥글: 출처·소급 표시 설명

### 2-2. 저장소 `/repo/<owner>/<name>`
1. 히어로: 카테고리·언어 칩 · 이름 · 설명(star-trend 메타) · 깃허브 링크 · 숫자 3개(종합 순위 · 지수 · 스타 순위)
2. 신호별 백분위 막대 5개(가중치 · 백분위 · 원값 한 줄, 빠지면 "빠짐")
3. 지수 구성 쌓은 막대 + 재분배 설명 한 문단
4. **12주 추이**: 위 지수 선(순위 점) · 아래 주별 기여 쌓은 막대, 12주/4주 전환, 소급 주는 옅게 + "소급"
5. 이번 주 원래 값 표(신호 · 값 · 출처 · 상태)

### 2-2b. 저장소 v2 — 저장소 해설 (F10, 시안 v2 — 2026-11-14 합의)
캔버스 아트보드 "v2 저장소"(remotion — 사용으로 오른 예) · "v2 화제 절"(claude-code — 글이 있는 예) · "v2 홈 TOP 10 표".

1. 히어로: v1 + "AI 해설 · <주>" 칩, 숫자 카드 아래 지난주 값(순위 변화), star-trend 카드가 있으면 링크(없으면 그렇다고 한 줄)
2. 절 목차(칩 줄): 3줄 요약 · 이번 주 동향 · 무엇인가 · 화제 · 신호 인사이트 · 신호와 추이 · 근거
3. **AI 작성 안내**(보라 상자): 공개 자료 근거 · 사람 미검토 · 확인/추정 뜻 · 숫자는 코드. "AI 해설"·"코드 계산" 범례 칩
4. **01 3줄 요약**(AI): 무엇인지 / 이번 주 왜 올랐나 / 무엇을 볼까 — 줄마다 근거 번호·확인/추정
5. **02 이번 주 동향**: 왼쪽 코드 표(항목 × 지난주·이번 주·지난 4주 평균, 이번 주 릴리스) · 오른쪽 AI 항목 2~4개
6. **03 무엇인가·어떤 역할**(AI): 푸는 문제 · 구조 · 쓰는 사람 · 대안과 비교한 자리
7. **04 어디서 어떻게 화제가 됐나**: 코드 — 이번 주 HN·GeekNews 수, 12주 HN, 글 목록(곳·제목 링크·점수·댓글·날짜·글이 가리킨 곳) · AI — 계기 · 반응의 요지 · 읽는 법 + **화제의 성격 칩**(소개·호평·논란·질문)
8. **05 신호 인사이트**: 코드 관찰 카드 I1~I7(신호 색 점 · 큰 숫자 · 한 문장) · AI "지켜볼 점" 2~3개
9. **06 신호와 추이**: v1의 백분위 막대 · 지수 구성 · 12주 추이 · 원래 값 표 그대로
10. **07 근거**: 번호 · 제목(120자) · 사이트 · 날짜, 지난 해설 주 목록, 해설 기준(모델·게이트 제외 수)
- 해설이 없는 저장소: 히어로 · 05 코드 관찰 · 06만. 지난 해설이 있으면 "마지막 해설: <주>" 링크.

### 2-3. 방법 `/about`
1. 세 단계(백분위 → 가중 평균·재분배 → 기여분)
2. 다섯 신호 표(주간 값 · 출처 · 가중치 v1)
3. 한계(AI 판정 · 소급 · 패키지 연결 · 언급 동점 · ecosyste.ms 라이선스)

## 4. 시안에 쓴 데이터

- 실제 `data/index/2026-11-01.json`(첫 정기 수집 주) 값. 관점 노트 A·B 는 같은 주로 고른 실제 결과, C·D 는 그때 이력 부족.
- 저장소 화면의 12주 추이·설명은 자리 표시 — 소급(T2-5)이 끝나면 실제 값으로 그린다.

## 5. 검토 포인트 (합의할 것)

1. 화면 3개 구성과 메뉴 이름
2. 홈의 순서(TOP 10 → 신호별 → 관점 노트)
3. 신호 색 5개와 빠진 신호 점선 칩
4. 저장소 화면 12주 추이 표현(선 + 쌓은 막대)
5. ~~사이트에 LLM 글을 넣지 않는 것(숫자만)~~ → v2에서 저장소 해설은 넣는다(D13)

**시안 v2 검토 포인트 (2026-11-14)**
1. 저장소 화면 절 순서 01~07 (요약 → 동향 → 무엇인가 → 화제 → 인사이트 → 신호와 추이 → 근거)
2. 코드 관찰 I1~I7 의 종류·문구 (SPEC F10-1)
3. 화제 절 — 글 목록 + 화제의 성격 칩(소개·호평·논란·질문)
4. 홈 TOP 10 표의 AI 한 줄 위치·길이
5. AI 해설(보라)과 코드 계산(남색)을 나누는 표시 방식
