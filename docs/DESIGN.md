## 1. IA (정보 구조)

```
/                      이번 주 (최신 주)
├─ ?week=YYYY-MM-DD    지난 주 (소급 주 포함 — "소급" 표시)
├─ /repo/<owner>/<name>  저장소 상세
└─ /about              지수는 이렇게 만든다 (방법·출처·한계)
```

- 머리 메뉴 3개: 이번 주 · 저장소 · 지수는 이렇게. 주 선택은 이번 주 화면 머리에.
- 모든 화면 바닥글에 출처 표기(star-trend 공개 데이터 · GitHub API · pypistats·npm · **ecosyste.ms** · HN·GeekNews)와
  "숫자는 코드가, 글은 AI 초안을 사람이 검토" 안내 (TASKS T4-5).
- 사이트는 `data/site/` 파생 데이터만 읽는다(T4-3). LLM 글(초안·해설)은 사이트에 넣지 않는다 — 비공개 저장소에만(D7).

## 2. 와이어프레임 (화면별 구성)

### 2-1. 이번 주 `/`
1. 머리: 로고 · 메뉴 · 주 선택
2. 어두운 히어로: 기간·회차 · 한 줄 제목 · 숫자 3개(후보 수 · 스타 TOP 10 중 지수 TOP 10 · 패키지 확인 후보) · 가중치 범례
3. **종합 TOP 10 표**: 순위 · 저장소(+카테고리 칩) · 지수 · **신호 기여 쌓은 막대**(합 = 지수) · 스타 순위 · 빠진 신호 칩(점선)
4. **신호별 TOP 5** 카드 5개(스타·기여·사용·언급·포크). 값이 없으면 언제 채워지는지 안내
5. **관점 노트** 카드 A~D(규칙 한 줄 + 저장소·근거 숫자). 이력 부족이면 안내
6. 바닥글: 출처·소급 표시 설명

### 2-2. 저장소 `/repo/<owner>/<name>`
1. 히어로: 카테고리·언어 칩 · 이름 · 설명(star-trend 메타) · 깃허브 링크 · 숫자 3개(종합 순위 · 지수 · 스타 순위)
2. 신호별 백분위 막대 5개(가중치 · 백분위 · 원값 한 줄, 빠지면 "빠짐")
3. 지수 구성 쌓은 막대 + 재분배 설명 한 문단
4. **12주 추이**: 위 지수 선(순위 점) · 아래 주별 기여 쌓은 막대, 12주/4주 전환, 소급 주는 옅게 + "소급"
5. 이번 주 원래 값 표(신호 · 값 · 출처 · 상태)

### 2-3. 방법 `/about`
1. 세 단계(백분위 → 가중 평균·재분배 → 기여분)
2. 다섯 신호 표(주간 값 · 출처 · 가중치 v1)
3. 한계(AI 판정 · 소급 · 패키지 연결 · 언급 동점 · ecosyste.ms 라이선스)

## 4. 시안에 쓴 데이터

- 실제 `data/index/2026-11-01.json`(첫 정기 수집 주) 값. 관점 노트 A·B 는 같은 주로 고른 실제 결과, C·D 는 그때 이력 부족.
- 저장소 화면의 12주 추이·설명은 자리 표시 — 소급(T2-5)이 끝나면 실제 값으로 그린다.

## 5. 검토 포인트 (합의할 것)

1. 화면 3개 구성과 메뉴 이름
2. 홈의 순서(TOP 10 → 신호별 → 관점 노트)
3. 신호 색 5개와 빠진 신호 점선 칩
4. 저장소 화면 12주 추이 표현(선 + 쌓은 막대)
5. 사이트에 LLM 글을 넣지 않는 것(숫자만)
